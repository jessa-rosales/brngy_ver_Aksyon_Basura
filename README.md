Aksyon Basura is an integrated web and mobile waste management ecosystem designed for
Barangay Nazareth in Cagayan de Oro City, featuring real-time mobile GPS collection monitoring, 
spatial reporting for local residents, and centralized administrative dispatch analytics.

- Key Features
       Citizen Waste Reporting:
              Residents can instantly submit geotagged photos and locations of uncollected garbage or illegal dumping.
              This enables barangay officials to quickly identify cleanup priorities and take action.
       Real-Time GPS Tracking:
              Sanitation teams can view live garbage truck locations and optimized collection routes on their mobile screens.
              Drivers, collectors, and street sweepers can update their progress as they complete assigned paths.
       Barangay Admin Dashboard:
              Barangay officials manage operations from a centralized web portal that tracks field workers and incoming resident
              reports. The dashboard simplifies assigning tasks, verifying completed cleanups, and reviewing service performance.
       Geospatial Mapping (PostGIS):
              The system uses PostGIS spatial querying to pinpoint report coordinates with high accuracy across Barangay
              Nazareth. This helps map out recurring waste hotspots and streamline neighborhood collection routes
       Role-Based Mobile App:
              The mobile application automatically tailors its interface based on whether a resident, driver, or collector
              worker logs in. Each user type gains access only to the exact tools and updates needed for their daily task.
